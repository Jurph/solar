Prompting approach v2: 
------------------------

Ollama lets us generate structured JSON so we don't have to worry about cajoling the model into its lane as aggressively. 
Also, peer-reviewed studies suggest that while the role-play style prompt above works great with large models (like you),
smaller models have limited context and respond better to a structured, terse, almost mechanical prompt. With that in mind,
we're going to try a different style altogether. 

The dialogue exchange will be assembled from parts ("in this scene we're doing Request, Response, Readback") outside the prompting. 
Each particle (Request, etc.) will have 5+ examples hard-coded in the function that we use to build prompts, and we'll pull 3 examples 
and a counterexample. The rest of the info will be from the Navigational Context and various parts of the World Model. (See below for 
a future stretch-goal example of drawing a flight plan from a Planet. We're not doing that yet.)

The System Prompt will be static throughout (!) and only the User prompt will change. 

-----

New System Prompt:

Generate a message for a spaceflight simulator. 
You write concise and conversational dialogue that uses
the context of the scene and situation. Observe the
SITUATION, place yourself in the ROLE, and write a 
MESSAGE to the RECIPIENT. 

-----

The new User Prompt will be much more like JSON: 

role: Captain Rodriguez, the pilot of the STELLAR HORIZON 
situation: STELLAR HORIZON is a ship intending to fly to Earth from Mars. The STELLAR HORIZON needs permission from MARS CONTORL to lift off from Mars on flight azimuth 32.
sender: STELLAR HORIZON 
recipient: MARS CONTROL 
altitude: 0 km
inclination: 32 degrees 
speed: 0 m/s
example1: Mars Control, this is STELLAR HORIZON requesting permission for lift-off on three two. 
example2: Mars Control, STELLAR HORIZON here. We're planned for 32 degrees departure angle, prepped for launch, and awaiting your clearance. 
example3: Mars Control, STELLAR HORIZON. Request launch clearance to inclination 32 degrees.
counterexample: [DON'T DO THIS!] Earth Control, we want to launch the STELLAR HORIZON to Earth please.
last_dialogue_line: N/A 

RETURN:
{ "message": "<pilot_radio_reply>" }

-----
